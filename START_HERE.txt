🔧 CONFIGURATION

For SQLite (Default - No Setup):
  Just run: python quick_start_database.py

For PostgreSQL:
  Create LLM_CI/db_config.json:
  {
    "type": "postgresql",
    "host": "localhost",
    "port": 5432,
    "user": "postgres",
    "password": "password",
    "database": "dbname"
  }

For MySQL:
  Create LLM_CI/db_config.json:
  {
    "type": "mysql",
    "host": "localhost",
    "port": 3306,
    "user": "root",
    "password": "password",
    "database": "dbname"
  }

Or use environment variables in .env file
See: LLM_CI/db_config_examples.py for more options
